# PhoneForm AI PC 0.1.0-dev

Windows 11 x64 内部试用预览版 / Internal evaluation prerelease.

## 中文

- 初版离线流程：项目、模板、逐份 PDF/JPG/PNG 导入、本地辨识、人工覆核及四表 Excel 输出。
- 支持繁中、简中、英文；界面、问卷和 Excel 标题语言分别设置。
- 随包 Java、OCR 模型及本地引擎，终端用户首次使用无需下载资源。
- 历史记录为 80 项自动化测试通过；30/1000 份合成工作流及当时六份 Excel 原生开启检查通过。范围和限制见历史证据，不能推定为真实纸本准确率或完整发布验收。
- 本 Release 保存原 MSI。**当时完整源码未保留；本标签和自动生成的 Source code 压缩包只含归档说明与证据，不是该版本的完整源码。** 当前源码见 `v0.2.0-dev` / `main`。
- 干净 Windows 安装、完整 DPI/人工流程及部分故障与授权声明审计仍待验收；此版本作为历史预览版保留。

## English

- Initial offline workflow: projects, templates, one-questionnaire-at-a-time PDF/JPG/PNG import, local recognition, human review and four-sheet Excel export.
- Traditional Chinese, Simplified Chinese and English, with separate interface, questionnaire and Excel-heading settings.
- Bundled Java runtime, OCR models and native engines; no first-run resource download for users.
- Historical evidence records 80 automated tests, synthetic 30/1,000-submission workflows and six native Excel opening checks. These are limited acceptance results, not real-document accuracy or complete release certification.
- This release preserves the original MSI. **The complete historical source snapshot was not retained. This tag and its generated Source code archives contain archival documentation and evidence only, not the complete 0.1.0-dev source.** See `v0.2.0-dev` / `main` for current source.
- Clean-Windows installation, complete DPI/manual journeys and remaining failure/notice audits are pending. This installer is retained as a historical evaluation build.
