# PhoneForm AI PC 0.3.1-dev

本版本改善大量問卷的覆核清單與草稿恢復保護，沿用 `marks-1` 辨識引擎及既有資料契約。應用版本 `0.3.1-dev`、MSI 產品版本 `0.3.1`；保留升級識別與加密資料位置。不新增 GitHub Release，不改動原兩個 Release、標籤或附件，前三版本機 MSI 保留。

This development update improves review-list reads and protects pending editor recovery. The `marks-1` detector and existing data contracts are unchanged. Application version: `0.3.1-dev`; MSI product version: `0.3.1`. Upgrade identity and encrypted storage location remain compatible. No new GitHub Release is created, and the existing two Releases, tags, assets and earlier local installers are preserved.

## Changes / 修改

| Phase | 繁中說明 | English |
|---|---|---|
| PC-R4.1 | 覆核清單改用 SQL 搜尋、篩選與分頁；保留前導零、Unicode 搜尋及 `%`／`_` 的文字意義。刷新不因換頁而清除單份工作台選取，過期查詢不能覆蓋新結果。 | SQL review paging/filtering/search, with literal wildcard characters and Unicode matching; stale-response protection and stable workspace selection. |
| PC-R4.1 | 已確認問卷從「待覆核」消失後仍可前往下一份。批量重跑固定問卷修訂與目前任務，避免默默改跑較新資料。 | Cross-page neighbors remain available after confirmation removes the current item from a pending filter. Rerun selections pin revisions and current jobs. |
| PC-R4.1 | 專案、任務及匯出歷史改讀摘要；任務只載入前 200 筆，但顯示真實總數。另存歷史工作簿時才讀取該筆完整快照。 | Lightweight project/task/export history summaries; at most 200 task rows with global counts. Full export snapshots are loaded explicitly when saving them. |
| PC-R4.2 | 題目／整組／矩陣／辨識設定編輯器加入恢復載入屏障。讀取或解碼失敗保留原稿，可重試或明確放棄；窄窗卸載編輯器不能繞過未套用草稿。 | Typed editors block edits and commits until recovery loads. Failures retain their source and offer retry or explicit discard. Unmounted editors cannot bypass pending recovery. |
| PC-R4.2 | 保存直接讀取最新編輯值，防止最後輸入在重新繪製前被舊值覆蓋；校準縮放上限與持久設定統一為 500%。 | Commits read the current editor value, including edits made before recomposition. Calibration and persisted zoom limits both use 500%. |

資料庫仍使用 schema 2；新增可重建索引，不改寫答案、確認或歷史快照。查詢計數仍需讀取符合範圍的資料；分頁不代表整個查詢成本只與當頁筆數有關。

Schema 2 is retained with additive, reconstructible indexes. Answers, confirmations and historical snapshots are not rewritten. Counts still inspect the relevant records; pagination does not make total query cost proportional only to page size.

## Verification / 驗證

2026-10-22：**166 項不同自動化測試全部通過，零失敗、錯誤或跳過**（domain 37、excel 8、data 37、vision 33、desktop 51）。涵蓋現有答案／候選來源／四表契約、SQL 語意與計數、過期查詢、重跑版本保護及 12 項恢復安全測試。兩項初驗問題已修復：安全測試的 sentinel 改存合法 JSON，保留全部加密斷言；已保存矩陣的幾何比較容許 `1e-6` 浮點重建誤差，代碼或 `.001` 幾何變更仍會被攔截。

On 2026-10-22, **all 166 distinct automated tests passed**, with zero failures, errors or skips. Existing answer/provenance/four-sheet contracts, SQL queries, stale responses, rerun guards and 12 editor-recovery safety tests are covered. Initial failures were repaired while retaining the encryption assertions and meaningful matrix-change rejection checks. No external original PDFs or deleted datasets were used. Native Microsoft Excel was not opened.

這個另行執行的規模變體不增加 166 項回歸總數。每份 10 個頁槽、100 個答案目標；142 份缺末頁，共 9,858 筆頁面參照；資料庫有 100,000 個匿名答案值及 100,000 個候選觀察記錄，沒有實體影像。順序為舊式完整讀取後再跑 SQL，使用暖快取，每操作只量一次；不可推論冷啟動、GUI 延遲或普遍效能倍數。它不測影像可用性、OCR、採集寫入或工作簿速度。臨時工作區測後清除，只保留程式與匿名彙總。

This opt-in scale variant is reported separately. Bulk-seeded encrypted metadata uses 10 page slots and 100 answer targets per submission; 142 submissions lack their last page, giving 9,858 page references. It contains 100,000 anonymous answer values and 100,000 observation entries, with no physical images. Legacy reads ran first, then SQL, using warm caches and a single observation per operation. Results do not measure cold starts, GUI latency, asset availability, OCR, collection throughput or workbook performance, and do not establish a general speed multiplier. Temporary workspaces are removed after validation.

自包含程式與 MSI 構建成功；隨包 Java 可執行，7 個資源雜湊一致，6 個應用 JAR 未混入測試類或工作簿／PDF／資料庫／密鑰。舊三版 MSI 雜湊未變。三語程式文案已同步，但本輪未重新進行實際 GUI、DPI、完整三語人工流程、真實掃描泛化及乾淨 Windows 安裝／升級驗收。

The self-contained distribution and MSI built successfully. Bundled Java executed, seven resource hashes matched, and six application jars were checked for test/private artifacts. Earlier local MSI hashes are unchanged. Three-language text is supplied, but actual GUI/DPI journeys, full manual language flows, real-scan generalization and clean-Windows installation/upgrade remain unverified for this update.
