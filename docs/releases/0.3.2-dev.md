# PhoneForm AI PC 0.3.2-dev

本版補齊日常編輯恢復、影像顯示與任務中心的操作缺口。應用 `0.3.2-dev`、MSI `0.3.2`，資料庫維持 schema 2、升級識別與儲存位置不變。沿用既有離線引擎與凍結辨識參數；不新增空白問卷參考或雲端服務。

This update closes everyday editor-recovery, image-display and task-center gaps. App version: `0.3.2-dev`; MSI version: `0.3.2`. Schema 2, upgrade identity and encrypted storage location remain compatible. Offline engines and frozen recognition parameters are unchanged, with no blank-reference workflow or cloud service.

沒有加入跨掛載 bitmap 快取；已有的 LazyColumn 仍按需掛載。此版本不宣稱曾一次載入所有問卷影像，也不把影像載入改善計作 OCR 準確率提高。

There is no shared bitmap cache across mounts. Existing LazyColumn views remain demand-driven; the update does not imply that every questionnaire image was previously loaded at once, or that display changes improve recognition accuracy.

辨識設定、人工答案、固定頁槽、候選來源與四表快照仍沿用既有業務契約。此版本沒有重新調整辨識參數；真實文件的答案表現須另按獨立實測報告，不以介面改進推算。中文手寫與自由文字繼續人工處理。

Recognition settings, human answers, fixed page slots, candidate provenance and four-sheet snapshots retain their existing contracts. The detector is not retuned. Answer performance on real documents requires a separate independent measurement and is not inferred from UI improvements. Chinese handwriting and free text remain manual.

矩陣以一列為一個目標；人工文字與不支援的標記方式屬預設人工模式，不把人工棄答當作 OCR 錯誤。量測只執行一次固定人工區域／核心設定，使用相同凍結引擎、144 DPI、原始 PDF 方向，同一份已填寫文件分別經正式加密匯入流程成為範本與問卷，未提供真值給辨識器，也沒有人工答案回填或空白參考。這是有人工校準條件的單輪結果，不能證明對新掃描的對齊或泛化能力，也不能加入 216 項匿名基線回歸當作通過。

Each matrix row is one target. Text and unsupported mark styles intentionally require manual handling; those abstentions are not OCR errors. Each document was run once with frozen human-selected regions/cores and the unchanged engine, at 144 DPI in raw PDF orientation. The same filled document was imported through the production encrypted pipeline as template and submission. Recognition received no truth or human answers, and no blank reference was used. This is a conditional manual-calibration result, not evidence of alignment/generalization to new scans or an additional pass within the 216-test baseline.

兩份辨識任務均到達 `READY`，原始完整報告及 SHA 摘要均已保存並核對；隨後兩次原生測試程序均以 **`-1073740791`（`0xC0000409`）** 退出。因此可報告已保存的答案量測，但完整程序生命週期測試為 **FAILED**。故障模組及實際退出原因尚未確定，不把某個模型警告或零候選直接判定為崩潰原因。

Both recognition jobs reached `READY` and saved complete raw reports with verified SHA digests before both native test processes exited with **`-1073740791` (`0xC0000409`)**. Saved answer measurements can therefore be reported, while the full process-lifecycle tests are **FAILED**. The fault module and cause remain unverified; neither a model warning nor zero candidates establishes the crash cause.

後續辨識工作須優先處理：144 DPI 下的小方框低於固定 14 像素定位門檻；數字核心邊界碰墨、表格線與裁切造成的保守拒絕；數字／日期 OCR 的空讀、格式失敗及增強衝突；中文模型要求但未隨包的竪排子模型，以及獨立定位原生退出問題。診斷是量測值與失敗原因彙總，沒有以放寬門檻或人工答案重新計分。

Priority gaps are small fitted checkboxes below the fixed 14-pixel minimum at 144 DPI; ink touching printed-core boundaries, table lines and cropping; empty/invalid/conflicting number/date OCR; absent Chinese vertical submodels requested by bundled configurations; and independent investigation of the native-process exit. Diagnostics summarize measurements and rejection reasons. No thresholds were relaxed or human answers substituted to improve these scores.
